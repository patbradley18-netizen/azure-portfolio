The pipeline that says no: event-driven ingestion with a data contract, quarantine, idempotency and poison handling

Drop a file in inbox/. Event Grid tells a Function; the Function checks the file against its contract and either queues it, quarantines it with a reason, or records it. A container pulls the queue, refuses bytes it has loaded before, loads the rest with the same OPENJSON path as every earlier build, and moves a message that keeps failing to a poison queue. Every decision is a ledger row the build #13 API serves. Anchor phrase: every file is guilty until the gate clears it. Expand the contract to read the rules.

The contract (contracts/acs5_county.yaml)
# Data contract: a raw ACS 5-year county pull as the Census API returns it (the shape build #6-#9's fetch_acs.py saves).
# File name convention: acs5_<year>_<set>_county.json  ->  dataset_id acs5_<year>[_<set>] (shelter is the unnamed default set).
# The validator checks every rule below; one failure quarantines the file with the first failing rule as the reason.
name: acs5_county
file_pattern: '^acs5_(?P<year>20\d{2})_(?P<set>[a-z]+)_county\.json$'
format: json_array_of_arrays        # header row, then one row per county
header:
  required: [NAME, state, county]   # the Census API appends state and county last; variable codes go first
  variable_pattern: '^B\d{5}[A-Z]?_\d{3}E$'
  min_variables: 1
  max_variables: 60
rows:
  min: 3100                          # 3,221 counties + PR 78 in a full pull; a partial pull is a quarantine
  max: 3300
  state_fips_pattern: '^\d{2}$'
  county_fips_pattern: '^\d{3}$'
  unique_key: [state, county]
values:
  numeric_or_null: true              # every variable cell parses as a number, or is null/empty
  allow_negative_sentinels: true     # -666666666 etc. are Census suppression codes, loaded as NULL + text flag
  max_value: 1000000000
dataset_id:
  template: 'acs5_{year}{set_suffix}'
  set_suffix: { shelter: '', veterans: '_vet', tenure: '_tenure', rentburden: '_rentburden' }
  allowed_sets: [shelter, veterans, tenure, rentburden]

What this cannot say

One contract covers one file family (raw ACS county pulls); anything else is quarantined by design. The public limits on the ledger endpoint are build #13's. Container Apps Jobs were the plan for the loader: new Container Apps environments on this subscription are express-only in every allowlisted region and express has no jobs, so the loader runs on Azure Container Instances instead — the same image, the same identity pattern, per-second billing in fractions of a cent. The validator re-reads the blob; the loader re-hashes and re-checks it; neither trusts the message. Snapshot taken 2026-10-17 05:25 UTC.
