How much does straight-line lie? Road miles to the nearest VA medical center for 895 counties

Build #10 measured straight-line distance from every county's population center to the nearest VA medical center and said, on the page, that it understates travel. This build measures by how much: a capped, ledgered sample of 895 counties routed by road, the ratio of road miles to straight-line miles (the detour index) by distance band, the counties where it is worst, and build #10's base counties corrected. Anchor phrase: measure the error in your own measure. Expand any query to read the T-SQL.

Q22. The detour index by straight-line band

Across 895 sampled counties, the road is on average 1.30× the straight-line distance to the nearest VA medical center (veteran-weighted 1.39×) — the textbook 1.3 planning factor, measured. The index is highest in the nearest band (1.39× within 30 miles: city grids, rivers and bays) and flat at about 1.28× beyond it. Only 11% of counties have a detour index above 1.5. Straight-line understates by a fairly constant third, so build #10's rank order of who is far mostly stands; its miles do not.

Sample: build #10's 25 base counties plus a seeded stratified random sample by straight-line band (allocation {'0-30': 183, '100+': 147, '30-60': 280, '60-100': 263} of {'0-30': 663, '100+': 490, '30-60': 1014, '60-100': 952} counties), 900 calls cap. Query (join to the materialised access table + ROLLUP)
WITH r AS (
  SELECT fips, dest_sta_no, road_meters / 1609.344 AS road_miles, travel_seconds / 60.0 AS travel_min
  FROM col.route_ledger WHERE road_meters IS NOT NULL),
j AS (
  SELECT a.fips, a.county, a.state_abbr, a.veterans, a.vamc_miles, r.road_miles, r.travel_min, r.road_miles / NULLIF(a.vamc_miles, 0) AS ratio,
         CASE WHEN a.vamc_miles <= 30 THEN '0-30' WHEN a.vamc_miles <= 60 THEN '30-60' WHEN a.vamc_miles <= 100 THEN '60-100' ELSE '100+' END AS band
  FROM col.county_access a JOIN r ON r.fips = a.fips AND r.dest_sta_no = a.vamc_sta_no)
SELECT COALESCE(band, 'all') AS band, COUNT(*) AS counties, SUM(veterans) AS veterans,
       ROUND(AVG(ratio), 3) AS mean_ratio,
       ROUND(SUM(veterans * ratio) / SUM(veterans), 3) AS vet_weighted_ratio,
       ROUND(MIN(ratio), 2) AS min_ratio, ROUND(MAX(ratio), 2) AS max_ratio,
       ROUND(AVG(vamc_miles), 1) AS mean_straight_miles, ROUND(AVG(road_miles), 1) AS mean_road_miles, ROUND(AVG(travel_min), 0) AS mean_drive_minutes,
       ROUND(100.0 * SUM(CASE WHEN ratio > 1.5 THEN 1 ELSE 0 END) / COUNT(*), 1) AS pct_counties_ratio_over_1_5
FROM j
GROUP BY ROLLUP(band)
ORDER BY CASE band WHEN '0-30' THEN 1 WHEN '30-60' THEN 2 WHEN '60-100' THEN 3 WHEN '100+' THEN 4 ELSE 5 END;

Q23. Where the crow lies most

The worst detours are where the road has to go around something: Inyo CA (88 straight-line miles, 235 by road, 2.7×), then Leelanau MI (2.6×) and Chugach AK (2.4×). Mountains, lakes and sounds make the index, not distance. Some of these are artefacts of the method: the route goes to the straight-line-nearest medical center, which across a lake is the wrong hospital — the road-nearest one is the fix, and it is build #12's problem, not this page's.

Query (LEFT JOIN to the ledger)
WITH r AS (
  SELECT fips, dest_sta_no, road_meters / 1609.344 AS road_miles, travel_seconds / 60.0 AS travel_min
  FROM col.route_ledger WHERE road_meters IS NOT NULL),
q20 AS (
  SELECT TOP 25 fips FROM col.county_access WHERE veterans >= 5000 AND vamc_miles > 60 ORDER BY vet_share DESC)
SELECT a.county, a.state_abbr, a.veterans, ROUND(a.vet_share, 1) AS vet_share, a.vamc_name,
       ROUND(a.vamc_miles, 1) AS straight_miles, ROUND(r.road_miles, 1) AS road_miles, ROUND(r.road_miles / a.vamc_miles, 2) AS ratio,
       ROUND(r.travel_min, 0) AS drive_minutes, ROUND(a.site_miles, 1) AS nearest_site_straight_miles
FROM col.county_access a JOIN q20 ON q20.fips = a.fips LEFT JOIN r ON r.fips = a.fips AND r.dest_sta_no = a.vamc_sta_no
ORDER BY a.vet_share DESC;

Q25. The ledger

898 router calls in 1 batch(es); 895 routed, 3 failed; cap 900; file lines 898. The cap is the contract: the script refuses to exceed it, and the ledger is how you check it did not.

Query (GROUP BY batch)
SELECT batch_id, COUNT(*) AS calls, SUM(CASE WHEN http_status = 200 AND road_meters IS NOT NULL THEN 1 ELSE 0 END) AS routed,
       SUM(CASE WHEN http_status <> 200 OR road_meters IS NULL THEN 1 ELSE 0 END) AS failed,
       MIN(called_at) AS first_call, MAX(called_at) AS last_call
FROM col.route_ledger GROUP BY batch_id ORDER BY first_call;

What this cannot say

Routes start at a county population center, not at a home, and end at the straight-line-nearest medical center, which is not always the road-nearest one. OSRM demo-server times are free-flow, no traffic. 895 of 3,144 counties were routed; the sampling rule is stated above and the sample is stratified, not random across the nation. Facilities are still the 2018 VAST list. The Azure part of this build was meant to be Azure Maps; the student subscription's region policy has no overlap with Azure Maps' regions, so the Azure part is the materialised access table and the ledger in SQL, and the router is OpenStreetMap's.

Data: OSRM demo server (project-osrm.org) on OpenStreetMap data (ODbL); VA VAST station list via HRSA GIS; U.S. Census Bureau centers of population and ACS 5-year 2023 B21001 (public domain).
