Azure Learning Portfolio

Small, free-tier Azure builds on public data. Each one teaches a Business Analyst skill, ships with its code and an honest README, and ends as a live page here. By Patrick Neil Bradley. Total cost so far: $0.

Build #1: Algorithmic Influence Detector (AID Lite)

Coordinated messaging in a public dataset of state-operator tweets: identical-message templates, a 44-account ring, who amplified whom, one-day blasts, and a control-tested null result against the Congressional Record.

Blob Storage · Azure SQL (free) · Functions · AI Language · AI Search · four stages

Build #2: Veteran employment, pulled weekly from BLS

Five Current Population Survey series for veterans and nonveterans, refreshed every Saturday by a Function whose API key lives in Key Vault and nowhere else.

Functions · Key Vault · Azure SQL (free) · SQL output binding

Build #4: Seven questions, seven queries, seven sentences

The queries a Business Analyst writes against the tables from builds #1 and #2: recession recovery times by veteran status, the Gulf War-era II spike, same-month year-over-year reads, and who produced vs amplified. Each answered in one sentence with its number and its caveat, computed from the result, not typed.

Azure SQL (free) · T-SQL: CTEs, window-style self-joins, FULL OUTER JOIN · no new resources

Build #5: Summarize a public report with Azure AI, with the cost controls first

The BLS veterans employment release through Azure AI Language on the free tier: records estimated before the call (39), a hard cap that refuses to run, a ledger of what the API actually billed (39), and a verifier that exact-matches every sentence and number against the source before the page is built. Includes the tier gate that changed the design and the sentiment signal that was discarded, with the reason.

Azure AI Language (F0) · Entra token auth · estimate, cap, ledger, verify · $0

Build #6: Snapshot to source, a cost-of-living warehouse that checks its own numbers

Two published county cost indices (TSCI, TCBI; 3,222 counties) loaded into the free Azure SQL database as a long-format warehouse with a data dictionary and provenance on every row, next to a fresh pull of the Census inputs they cite. Seven T-SQL questions: 16,084 of 16,110 county-field pairs match the Census to the dollar, the rest are suppressed in both, and the published arithmetic recomputes with zero mismatches.

Azure SQL (free) · Key Vault for the Census key · OPENJSON bulk loads · FULL OUTER JOIN reconciliation · $0

Build #3: This site

Azure Blob Storage static website, deployed by GitHub Actions on every push to main. GitHub signs in to Azure with OIDC through a managed identity: no deployment token, no secret anywhere. A secret-scan gate runs before every deploy.

Blob static website · GitHub Actions · OIDC federated identity
