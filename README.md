Small, free-tier builds on an Azure for Students subscription. Each one teaches one real skill, uses only public or made-up data, costs $0 (budget alert: $10/month), and ends with a README here plus a post on [patrickneilbradley.com](https://patrickneilbradley.com).

|---|---|---|---|
| 1 | [Algorithmic Influence Detector, stage 1](build-01-aid-lite/) | Blob Storage, Azure SQL (free), Entra auth, embeddings + clustering, T-SQL | Stage 1 published |
| 2 | Veteran employment data pipeline (BLS → Function → SQL) | Serverless, scheduling, API discipline | Planned |
| 3 | SQL analysis: the queries a Business Analyst writes | T-SQL, business writing | Planned |
| 4 | GitHub Actions deploy on every push | CI/CD | Planned |
| 5 | Summarize a public report with Azure AI, with cost controls | AI services, cost management | Planned |

Rules I hold myself to: cost first; no keys, passwords or connection strings anywhere in code or chat; non-commercial only; teach-don't-do; one build at a time.
